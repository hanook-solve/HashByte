Privacy Policy

Last updated: September 2026

1. Your images

HashByte compresses images entirely on your own computer. Your image files are never uploaded, transmitted, or stored anywhere by us.

2. What we do collect

HashByte checks a small remote file on launch to see if an update is available. This check does not send any image data or personal files — only a request for the current version number.

3. Licensing data

If you activate a license, your license key and a device instance ID are sent to Lemon Squeezy (our licensing provider) to verify activation. This is stored locally on your device at %APPDATA%\HashByte\license.json and with Lemon Squeezy for validation purposes. See Lemon Squeezy's privacy policy for how they handle payment and license data.

4. Analytics

HashByte does not include analytics, tracking, or telemetry beyond the update-version check described above.

5. Changes

This policy may be updated as the app evolves. Check this page for the latest version.

6. Contact

Questions can be raised via GitHub Issues.
